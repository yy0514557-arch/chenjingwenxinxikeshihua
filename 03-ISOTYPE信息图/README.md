# 03｜ISOTYPE信息图专项研究

> 独立研究项目，2026-11-24 自原 `02/18-ISOTYPE-基础图形设计方法` 迁出。**不是新的基础信息图形类型，也不是 02 的表现标签。**

## 项目研究对象

ISOTYPE（International System of Typographic Picture Education，国际图像文字教育系统）及其前身维也纳图像统计法。研究范畴包括历史来源、标准化图符、信息转译、重复象形单位、数据与视觉编码、真实案例和设计实施方法。

## 基本边界

**信息转译不是装饰性图标替换。** 必须区分历史原作、可证实采用 ISOTYPE 方法的现代作品和仅受其视觉风格启发的设计。数值图符须注明单位与取整规则；来源数据坚持一行一记录、一列一字段、一格一值。尚未核验的案例与实验不得标为已完成。
