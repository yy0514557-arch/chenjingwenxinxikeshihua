# ISOTYPE｜专项案例研究

本目录用于保留可核验的 **ISOTYPE 方法及其视觉语言研究案例**。它是 **独立专项案例研究区**，不是第十八种信息图形类型案例库。

## 案例记录对象

1. **历史原作**：可核实属于维也纳图像统计法／ISOTYPE 体系的作品，须标明馆藏、作者、年代、实际来源及版权状态。
2. **当代方法应用**：可证明采用图符词汇、标准化数量单位或系统性信息转译方法的作品，需记录真实数据口径及视觉编码证据。
3. **视觉借鉴案例**：只借鉴扁平象形符号与排版风格，须明确标记 `ISOTYPE-inspired`，不可冒充历史原作或完全方法级应用。

## 存储方式

```text
03-案例研究/
├── README.md
└── CASE-xxxx-作品名称/        # 有真实、已核验案例时才建立
    ├── 分析.md
    ├── 基础数据集.csv
    ├── 数据字典.md
    ├── 原图.png              # 仅在合法公开归档时存储
    └── 原图来源.md           # 无原图再发布权限时保留官方外链与来源
```

每个 CASE 先判五种基本信息逻辑，再标注一个或多个市场表现形式；**ISOTYPE 作为独立 03 专项方法关联记录，不属于 02 的表现形式标签**。案例应关注图符、重复单位、语法、色彩、排版与信息转换程序等可证实细节，并满足整个仓库“一行一记录、一列一字段、一格一值”的数据要求。

跨标签需要复用同一件作品时，按 [02 案例录入规范](../../02-信息图形类型案例/案例录入与知识回写规范.md) **只存一份真实原图**，其他目录通过链接关联，避免重复案例与冲突版本。实际创建目录位置可根据唯一主市场标签决定。

当前正式案例：**0**（不预置虚构 CASE）。
