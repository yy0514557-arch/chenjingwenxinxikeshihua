# 01｜ISOTYPE历史与文献

本目录收集与核验维也纳图像统计法、ISOTYPE 的发展、人物、文献、历史作品、出版与档案出处。先分析资料，再形成时间线或学术叙事，不能先画时间轴再编造年份。

## 核心研究线索

- Otto Neurath 与维也纳图像统计法（Vienna Method of Pictorial Statistics）的发展背景。
- Marie Reidemeister（Marie Neurath）参与的信息转译与教育设计。
- Gerd Arntz 的图符系统与视觉语言。
- ISOTYPE 名称的形成、历史传播、实际项目和后续设计影响。

## 来源与记录规范

每条资料记录：作者、题目、年份、出版/馆藏机构、URL或出版信息、页码、内容摘要、可靠性和使用权。历史图片如无公开再发布许可，仅保存经验证的原始来源链接和权利状态，不冒充已存本地图像。
