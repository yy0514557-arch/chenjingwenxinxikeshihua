# 04｜ISOTYPE设计实践

本目录按真实项目记录从数据与主题到视觉作品的完整 ISOTYPE 方法实践，不预存虚构研究结论或案例。

## 建议流程

1. 确定主题、目标读者、设计媒介与传播任务。
2. 核验来源，建立基础数据集、数据字典与缺失值说明；一格一值。
3. 根据数据关系选择 [01 的五种基础组织逻辑](../../01-信息图形数据逻辑/)之一；结合 [02 的表现形式标签](../../02-信息图形类型案例/)选择载体。
4. 建立图符语义字典，确定形状、比例、风格、排列规则和数量单位（如涉及定量）。
5. 对应字段绘制多个编码草案，逐项校验类别归属、单位、图例、文字与来源。
6. 检查图符一致性、信息层级、视觉节奏、可读性和可能造成的误读。
7. 保存源数据、可编辑设计文件、成品、实验记录和版权凭据。

## 项目记录

实际开展时按 `PROJECT-xxxx-主题名称/` 建档，建议含 `README.md`、`基础数据集.csv`、`数据字典.md`、`图符规范.md`、`设计分析.md` 和设计成品。没有证据的数量或制作过程不得编造；仅借鉴视觉风格的作品须标注 `ISOTYPE-inspired`。

可与 [06 具体主题信息图形设计](../../06-XXX主题信息图形设计/README.md) 的八阶段工作流衔接。
