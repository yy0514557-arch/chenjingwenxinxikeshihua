# 02｜ISOTYPE图符语言与视觉编码

## 研究目标

拆分 ISOTYPE 的基础图形语言、语义词汇、数据映射、统计数量表达、版式和信息转译，形成可复用的设计规范，而不将 ISOTYPE 简化为扁平图标风格。

## 关键研究维度

1. **图符词汇：** 同类对象采用一致的比例、轮廓、视角、视觉复杂度；记录图符 ID 与含义。
2. **数量语法：** 可计数的重复单位保持同尺寸。只有存在明确 `symbol_unit` 时才将图符个数映射到数量；说明截断、舍入与部分符号方案。
3. **图形与空间：** 基线、行列、间距、对齐、方向、分区、标题和图例；不能把位置差异自动解释为数值差异。
4. **色彩与文字：** 颜色承担类别区分、重点或说明时须稳定映射；单位、来源与必要语境不能省略。
5. **信息转译：** 明确目标受众→资料→数据结构→语义选择→图符编码→可读性/误读检验。

## 可检验的数据组织

采用原子化记录字段，如 `item_id`、`category_id`、`value`、`unit`、`symbol_id` 与 `source_id`；多标签或一对多关系必须采用关联表。无数量字段时可研究图符语言，但不可宣称这是定量统计图。

ISOTYPE 不等于 ISO 标准化公共标志，也不等于 [04 统计图形](../../04-统计图形分析/README.md) 的任何单一图表类型。详情见 [方法总论](../00-ISOTYPE概念与方法.md)。
