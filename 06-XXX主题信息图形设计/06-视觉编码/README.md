# 06｜视觉编码（侧重设计表达）

目标：将叙事中选定的字段与信息关系转换成清楚、准确、有审美完成度的视觉形式；不只挑选现成图表。

## 视觉编码维度

- **基本形态：** 点、线、面、体；位置、方向、长度、面积、体量、形状、密度、明暗与层次。
- **色彩与字体：** 色相、饱和度、明度、对比；字体、字号、字重、字距、行距、文字对齐与段落层次。
- **图形与图像：** 图标、ISO 图形／标准化图示、插画、摄影、照片裁切与拼贴、纹理、符号系统。
- **统计图形：** 根据 04 统计图形分析中的数据要求确定图表类型、聚合计算、比例尺、图例和单位。
- **设计表达：** 构图、网格、视觉节奏、负空间、视觉锚点、阅读动线、多图层协同与主题风格一致性。

## 编码审查

按 `数据字段 → 信息含义 → 视觉变量 → 图形形式 → 版式位置 → 校验规则` 记录编码选择。数量不能任意用面积/体积代表，类别色与连续量色标应分开；若仅为装饰，要标明不承担数值意义。

## 工作目录

- [01-视觉编码矩阵](./01-视觉编码矩阵/)：字段与编码通道的映射。
- [02-图形符号与统计图形](./02-图形符号与统计图形/)：图标、ISO 图形、统计图形和适用条件。
- [03-视觉风格与设计实验](./03-视觉风格与设计实验/)：平面/摄影/插画等方向、版式、字体、配色与原型实验。

建议在这一阶段进行若干视觉方案的比较，并记录编码准确性和设计效果，而非只确定单一画面风格。

## Gestalt 视觉组织检查

[05-Gestalt视觉组织原则](../../05-Gestalt视觉组织原则/README.md) 可作为本阶段的跨类型知觉组织方法库。请审查信息分组（接近、相似、区域和连接）、路径连续性、闭合、图底与整体组织是否忠实表达数据关系；如规则冲突，采用对照方案核验，而不是把格式塔视觉倾向直接视为事实或统计结论。

## ISOTYPE 图像语言

按主题需要，可引用 [03-ISOTYPE信息图](../../03-ISOTYPE信息图/README.md) 的图符词汇、标准单位重复与信息转译方法。应明确原始数据、图例、符号单位与数量映射；纯视觉风格借鉴不能冒充定量编码。
