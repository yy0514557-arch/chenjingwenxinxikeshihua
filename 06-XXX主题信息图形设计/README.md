## 与知识库其他部分的关系

- [01-信息图形数据逻辑](../01-信息图形数据逻辑/)：唯一的五种**基础组织逻辑**为编年型、层级型、编目型、字母表型、地理图型；每个主题按主导信息关系选定一种。
- [02-信息图形类型案例](../02-信息图形类型案例/)：各种**表现形式与市场应用标签**，例如流程图型、词云信息图、文字型/列表型、图片式等。一个主题可以使用多个标签，但标签不是第六类基础逻辑。
- [03-ISOTYPE信息图](../03-ISOTYPE信息图/)：标准化图符与图像统计专项，按选题需求在视觉编码阶段调用。
- [04-统计图形分析](../04-统计图形分析/)：依据数据结构选择具体的统计图形和计算方式，不能把“流程示意”误当数值统计图形。
- [05-Gestalt视觉组织原则](../05-Gestalt视觉组织原则/)：提供接近、相似、连续、图底等视觉组织原则，可在叙事和视觉编码阶段调用。

**三层判断：** 数据／信息组织逻辑（五选一）→ 表现标签（可多选）→ 平面／摄影／插画等视觉风格（独立选择）。

## 基础数据硬规则

1. 一行一个最小记录单元；**一列一个原子字段，一个单元格一个值**。同一列允许多个记录行，不得在单个单元格中混装多个独立数据。
2. 名义数据、量化数据、文本数据、图像引用均可纳入数据表；图片本体可存独立资源文件，用唯一文件路径或资源 ID 作为一个字段的值。
3. GPS 坐标若用于量化、投影或地理编码，应拆分为 `longitude` 与 `latitude`；数值与单位分离，多值关系用关联表。
4. 来源、采集时间、计量单位、数据缺失、计算/推断状态写进数据字典或来源记录；无数据不可编造。
5. 第 05 阶段应**引用基础表的字段与关联键**构造叙事，不破坏基础数据的原子性。
