# 04｜基础数据集构建

目标：把公共数据、文本、图像和自建资料转换成可检查、可关联、可直接驱动视觉设计的**原子化数据集**。

## 必须遵守

- **一行 = 一个最小记录单位；一列 = 一个原子字段；一个单元格 = 一个值。**
- 一个字段应有明确类型（名义、顺序、数值、时间、文本、图像引用、布尔、ID 等）、含义与缺失值规则；一列中可以有多行数据。
- 不把“姓名＋地点”“多个关键词”“一组经纬度”“金额＋单位”装在同一单元格；需要多值时拆字段或建立关联表。
- 可以记录图像、长文本，但一个单元格只对应一项图像引用或一条文本记录；图片本体与规范化引用分别保存。
- 把记录 ID、关联键、数据来源、采集口径、时间范围、可信度及计算方法写入数据字典/来源说明。
- 无法辨识或缺失的数值留空并标记，严禁为了可视化而猜测。

## 文件位置

- [01-规范化数据表](./01-规范化数据表/)：CSV / XLSX、必要的实体表与关联表。
- [02-数据字典与溯源](./02-数据字典与溯源/)：字段名、类型、单位、键、来源、质量、缺失与计算规则。

**建议成果：** `基础数据集.csv`、`数据字典.md`，依真实主题补充关联表及图像文件；不要预置虚构记录。
