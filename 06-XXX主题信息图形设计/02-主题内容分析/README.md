# 02｜主题内容分析（与大模型协作）

目标：将主题转化为可组织、可搜集数据且可视觉表达的信息问题。

## 必须分别讨论的三个维度

1. **基础信息组织逻辑（五选一）：** 编年型（阶段/先后）、层级型（上下位/等级）、编目型（类别/成员）、字母表型（检索索引）、地理图型（空间关系）。依据**主导数据关系**判断，不依据外形判断。
2. **表现形式标签（可多选）：** 按仓库 [02 的既有 17 类标签](../../02-信息图形类型案例/README.md) 选择，例如流程图型、文字型/列表型、词云信息图、图片式；保留主标签与辅助标签，并说明原因。
3. **视觉表现风格（独立选择）：** 平面图形、照片、插画、拼贴、信息排版等，不与基础组织逻辑、市场表现标签混为同一类。

## 与大模型讨论的输出

- 选题核心命题及拟回答的问题；
- 主要内容单元、相互关系、是否有先后或因果依赖；
- `primary_logic`（唯一）、`primary_tag`、`secondary_tags`（可选）、`visual_style`；
- 可选的统计图形、可能的数据字段、关键数据来源和待验证假设；
- 选择与排除其他类型的理由，优先记录证据而非只给标签。

**建议成果：** `内容结构.md`、`分类与视觉方案.md`、`大模型讨论记录.md`（开展时再新建）。
