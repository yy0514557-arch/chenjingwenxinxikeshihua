# 05｜叙事框架搭建

目标：从基础数据集中选择**若干字段和相互关系**，构建一个有明确主题、问题和阅读顺序的叙事方案，而非简单地把所有数据同时放进画面。

## 字段组合示例（仅为方法示例）

| 字段组合 | 可表达的叙事内容 | 可能的图形 |
|---|---|---|
| 名称 + 经度 + 纬度 | 地图上的对象及其位置 | 地图标记、地理分布图 |
| 地区名 + GDP 数值 + 年份 + 单位 | 指定时期的地区经济差异 | 地图、比较图 |
| 事件 + 顺序键 + 说明 | 阶段推进或过程 | 流程图、阶段链 |
| 词项 + 词频 | 主题文本中的关键词突出程度 | 词云（需实际频次） |
| 对象 ID + 类别 ID | 类别成员与分组关系 | 编目清单、矩阵 |

前述组合不是对真实选题的推断，也不意味着这些字段必须在一个原始文件内。通过 ID 关联基础表即可，保留原子性。

## 叙事设计要回答

1. 要让读者理解的**核心问题/判断**是什么？
2. 哪几列字段能够支持这个判断？记录在哪张表中、通过什么键关联？
3. 是顺序、对比、分类、层级还是空间叙事？与 02 的主类型是否一致？
4. 信息的主线、视觉锚点、关键证据、辅助注释、最终结论及阅读路径如何安排？
5. 每条结论是否确实由数据支持，还是只是设计假设？
