# 03｜数据搜集

按来源性质分开保留原始资料，不提前把多项数据混入一个字段。所有资料应可溯源、可核验；暂无法核实的记录须标记。

- [01-公共数据集](./01-公共数据集/)：政府开放数据、机构数据库、公开 CSV/XLSX、API 数据等；保留版本、发布时间、许可与访问日期。
- [02-文本文献](./02-文本文献/)：图书、论文、史料、报告、网页正文、采访或其他文本资料；记录精确出处、页码/定位、引用权限。
- [03-自建数据集](./03-自建数据集/)：调查、观察、人工编码、图像标注与自采样数据；保留方法、样本口径与采集过程。

**建议成果：** `数据来源清单.md`（开展时创建），记录各资料的标识、来源、时间、用途、许可状态、质量与待核实问题。

本阶段保留原始材料；下一阶段另建标准化基础数据集，不覆盖来源原件。
