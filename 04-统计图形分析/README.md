# 04-统计图形分析

本目录用于研究**信息图形案例中借用的统计图形**，重点是从源数据结构出发，识别统计图形的字段要求、数据转换与聚合计算、视觉编码及适用边界。

参考源码：
- [RAWGraphs App](https://github.com/rawgraphs/rawgraphs-app)
- [RAWGraphs Charts](https://github.com/rawgraphs/rawgraphs-charts)
- [RAWGraphs Core](https://github.com/rawgraphs/rawgraphs-core)

与现有目录的关系：
- [01-信息图形数据逻辑](../01-信息图形数据逻辑/)：五种基础信息组织逻辑，是本项目唯一的基础类型学。
- [02-信息图形类型案例](../02-信息图形类型案例/)：案例原图与配属分析文档的存放处。
- [03-ISOTYPE信息图](../03-ISOTYPE信息图/)：标准化图符、象形统计与信息转译专项，不等于某一种统计图形。
- **04**：以后用于解释案例“借用了什么统计图形、需要什么样的数据表、如何计算和编码”，不取代 01 的五种类型学分类。

**当前状态：仅初始化文件夹，尚不建立统计图形分类文档，也不对现有案例进行分析或修改。**
