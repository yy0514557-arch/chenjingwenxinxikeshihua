# 02｜数据映射与视觉编码

研究数据字段如何映射为图表维度，以及图表维度如何形成视觉表达。

## 1. 数据映射（Data Mapping）
- 原始数据字段（Data Fields）：输入表格中的列。
- 图表维度（Chart Dimensions）：图表定义的可映射槽位。
- 映射关系（Mapping）：字段与图表维度的对应关系。
- 聚合操作（Aggregation）：多个记录如何汇总为图形数据项。
- 视觉属性（Visual Attributes）：影响位置、大小、颜色、形状、连线或标签的属性。

## 2. 源码核验入口
- dimensions.js：维度 ID、名称、允许的数据类型、是否必需、是否支持聚合及默认聚合。
- mapping.js：分组、聚合、缺省值和数据转换。
- visualOptions.js：可调视觉参数。
- render.js 及图表主文件：映射结果如何转化为图形。

## 3. 视觉编码索引
- 位置（Position）：水平、垂直或空间位置。
- 长度（Length）：线段、条形长度。
- 角度（Angle）：扇区或方向角。
- 面积（Area）：圆面积、矩形面积等。
- 颜色（Color）：色相、明度、饱和度或连续色阶。
- 形状（Shape）：点形、符号和几何形态。
- 方向（Orientation）：方向、倾斜和排列。
- 连通性（Connectivity）：线、弧、路径和网络关系。
- 包含与分区（Containment / Partition）：嵌套、矩形分割和区域划分。
- 纹理与密度（Texture / Density）：点阵、网格、密度和聚集。
- 标签（Text / Label）：文字标注与层级提示。

以上是分析维度，不意味着每种图表都会使用所有视觉通道。

## 4. 聚合与计算记录
每个图表说明是否需要聚合、聚合维度、sum/count/mean 等方法、默认行为、缺省映射行为，以及是否包含排序、归一化、比例换算或几何布局计算。没有源码或官方文档证据时标记“待核实”，不要猜测。
