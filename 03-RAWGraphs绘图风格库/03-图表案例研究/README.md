# 03｜图表案例研究

本文件夹逐一研究 RAWGraphs 图表实现，并积累可复用的图表分析案例。

## 单个图表案例统一结构
1. 基本信息：中文名、英文名、源码 ID、官方描述、官方链接。
2. 图表解决的问题：比较、分布、层级、关系、时间或空间表达。
3. 数据结构：记录单位、字段、数据类型、必需维度与可选维度。
4. 数据逻辑：分组、聚合、排序、归一化或其他转换。
5. 统计与计算机制：区分统计方法和几何布局算法。
6. 视觉编码：位置、长度、面积、角度、颜色、形状、连线、标签。
7. 信息架构：类别、数值、关系、层级及其组织方式。
8. 视觉叙事：突出信息及阅读路径。
9. 可调参数：视觉选项、参数影响及合理使用范围。
10. 适用场景与局限：适合回答的问题、数据要求和可能误读。
11. 源码证据：文件路径、关键代码位置和核验日期。
12. 案例图与设计观察：区分可观察事实和设计推论。

## 命名规则
编号-中文名称-英文名称.md

建议覆盖 App 注册表中的全部图表，再按研究需要补充图表组合、变体和跨图表比较。

## 观察与推断
- **观察**：源码或图表中可以直接看到的事实。
- **推断**：依据数据映射和视觉结构得出的解释。
- **建议**：面向实际设计的操作建议。

三者必须分开写，不能将推断或建议伪装成 RAWGraphs 官方定义。
