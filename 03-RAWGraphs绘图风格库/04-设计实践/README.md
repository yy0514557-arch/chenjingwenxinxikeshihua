# 04｜设计实践

本文件夹把 RAWGraphs 的图表能力转化为实际信息可视化设计方法。

## 1. 图表选择
从任务而不是外观出发：比较类别或数值、展示时间变化、分析分布与密度、表达多变量关系、展示层级与组成、表达网络流向或转移、表达空间邻近与分区。选择前检查字段、记录数量、数据类型和目标读者的阅读任务。

## 2. 数据准备
- 明确每行记录代表什么。
- 检查字段含义、空值、重复值、异常值和单位。
- 区分名义、顺序、区间、比率等数据属性。
- 需要聚合时，说明聚合单位和计算口径。
- 不为适配图表而改变数据含义。

## 3. 视觉编码实践
- 优先使用与数据性质匹配的视觉通道。
- 精确比较任务谨慎使用面积、角度和装饰性形状。
- 连续数据与类别数据使用适当的颜色方案。
- 颜色不应成为唯一的信息区分手段。
- 控制标签密度、图例长度和视觉层级。
- 网络、流向和层级图特别检查交叉、遮挡与阅读路径。

## 4. 参数实验记录
记录原始数据及版本、图表类型、字段映射、聚合方式、视觉选项、导出尺寸与格式、修改前后差异、可读性与信息准确性评估。

## 5. 实践案例模板
1. 设计目标与受众；
2. 数据来源与数据结构；
3. 图表选择理由；
4. 字段映射方案；
5. 视觉编码方案；
6. 参数调整过程；
7. 导出与后期编辑；
8. 结果评估；
9. 问题与改进；
10. 可复用经验。

## 6. 重要原则
RAWGraphs 生成的图形是设计工作的起点，不等于最终的信息设计成品。导出后仍需检查标注、层级、图例、字体、颜色、版式、数据准确性和阅读顺序。
